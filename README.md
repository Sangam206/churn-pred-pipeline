# E-Commerce Customer Churn Prediction Pipeline

An end-to-end Machine Learning pipeline and REST API for predicting e-commerce customer churn using XGBoost and Optuna hyperparameter optimization.

---

## 📌 Project Overview

This project builds, evaluates, and serves a machine learning model to identify e-commerce customers at risk of churning. It includes:
- **Data Ingestion & Cleaning**: Handling missing values, duplicates, and outliers.
- **Preprocessing & Encoding**: Feature scaling with `StandardScaler` and categorical encoding with `OneHotEncoder`.
- **Hyperparameter Optimization**: Automated tuning using **Optuna** with 5-fold cross-validation (`TPESampler`).
- **Model Training & Evaluation**: Training XGBoost classifier and saving metrics (`train_metrics/` and `test_metrics/`).
- **REST API Deployment**: Production-ready **FastAPI** service for single and batch predictions.

---

## 🛠️ Requirements & Installation

1. Clone the repository and navigate to the project directory:
   ```bash
   cd churn-pred-pipeline
   ```

2. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```

---

## 🚀 How to Run

### 1. Run the Training & Evaluation Pipeline

To execute data ingestion, cleaning, splitting, encoding, Optuna hyperparameter tuning, model training, and evaluation:

```bash
python src/main.py
```

> **Outputs generated by the pipeline:**
> - Cleaned & split data in `splitting data/`
> - Encoded datasets in `after encoding/`
> - Saved model artifact in `model/model.pkl`
> - Saved preprocessor artifact in `model/preprocessor.pkl`
> - Evaluation logs and reports in `train_metrics/` and `test_metrics/`

---

### 2. Start the FastAPI Prediction Server

To launch the REST API server:

```bash
uvicorn api.app:app --reload --port 8000
```

- Interactive Swagger API Documentation: [http://localhost:8000/docs](http://localhost:8000/docs)
- Health Check Endpoint: `GET http://localhost:8000/health`
- Single Prediction Endpoint: `POST http://localhost:8000/predict`
- Batch Prediction Endpoint: `POST http://localhost:8000/predict/batch`

---

### 3. Test the API Endpoints

In a separate terminal window, run the API smoke test script to send sample single & batch prediction requests:

```bash
python api/test_api.py
```
